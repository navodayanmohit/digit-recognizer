# Handwritten Digit Recognizer

A desktop application that recognizes handwritten digits using a CNN trained on MNIST and EMNIST Digits datasets.

## Features
- Draw digits using a Tkinter interface.
- Predict digits from 0 to 9.
- Display prediction confidence.
- Train the model using MNIST and continue training on EMNIST.

## Requirements
- Python
- TensorFlow
- NumPy
- Pillow
- TensorFlow Datasets

## Run the Application
Run `digit_draw.py` to open the digit recognition interface.

## Model
The application uses `digit_model_improved.keras`.

## Training
Run `main2.py` to train a new model on MNIST and continue training on EMNIST.
